# Chhatrapati Shivaji Maharaj Legacy Website

A modern, responsive website dedicated to celebrating the legacy of Chhatrapati Shivaji Maharaj and organizing the upcoming Shivaji Jayanti celebration at JSPM University.

## 🚀 Features

- **Interactive UI Elements**
  - Custom cursor animation
  - Smooth scrolling navigation
  - Animated preloader
  - AOS (Animate On Scroll) implementations
  - Modal for donation QR code

- **Responsive Design**
  - Mobile-first approach
  - Adaptive layouts for all screen sizes
  - Hamburger menu for mobile navigation

- **Key Sections**
  - Hero section with parallax effect
  - Legacy showcase with achievement cards
  - Event details with animated cards
  - Historical gallery with hover effects
  - Contact information with interactive cards

## 🛠️ Technologies Used

- HTML5
- CSS3 (Custom variables, Flexbox, Grid)
- JavaScript (ES6+)
- FontAwesome Icons
- AOS Library
- CDN Resources

## 📦 Installation & Setup

1. Clone the repository:
```bash
git clone [repository-url]
cd shivaji-maharaj-legacy
```

2. No build process required. Simply open `index.html` in your browser.

3. For development, you may want to use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```

    --secondary-color: #138808;
